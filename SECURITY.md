# Security Policy

This tool runs locally, collects no data, sends nothing anywhere, and needs no API key or secret. It only reads the Markdown file, folder, or standard input you name, and it never changes a file. It writes nothing except the report on standard output (and usage errors on standard error).

If you find a case where the tool changes a file, or reports a file and line that do not match the real problem, please open an issue describing the exact commands and input. Do not include any real secret in the report.
